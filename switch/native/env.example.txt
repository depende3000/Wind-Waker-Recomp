# Run options of the native port on the Switch. Copy to the SD card as
#   switch/wind-waker-recomp/native/env.txt
# (scripts/switch/push.sh --native-env switch/native/env.example.txt). One NAME=value per line,
# nothing else on it; a line starting with # is ignored. Without the file the Switch defaults
# apply:
#   TWW_DISC=/switch/wind-waker-recomp/GZLE01.iso   (the disc image: push.sh --disc or --game)
#   TWW_RUN_DIR=/switch/wind-waker-recomp/native    (where the harness writes backtrace.txt)
#   TWW_PERF_EVERY=60                               (a "[tww] perf" line every 60 game frames)
#   TWW_STALL_S=90                                  (exit 11 after 90 s without a game frame)
#   TWW_ASPECT=16:9                                 (widescreen; 4:3 is the GameCube picture)
# Any TWW_* variable of native/README.md ("Running tww (phase 6)") works here. Remove the # in
# front of one of these to use it:
#
# Exit 0 when the title's sea is reached (milestone M7, "opening"):
#TWW_MILESTONE=opening
#
# Exit 0 after this many game frames:
#TWW_FRAMES=1800
#
# Log every scene the game creates:
#TWW_TRACE=scene
#
# Start-up check only: every static constructor ran and the 502 actor profiles are in place:
#TWW_SMOKE=static-init
#
# Write through a null pointer, to check the crash report ("[tww] CRASH" in the log, then
# Atmosphère ends the app with its own report):
#TWW_SMOKE=crash-test
#
# Do not start JAudio and the DSP (the game is silent either way for now):
#TWW_AUDIO=off
